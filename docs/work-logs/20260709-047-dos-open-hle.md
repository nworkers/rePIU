# DOS File Open HLE 작업 로그

## 결과

`DosVirtualFileSystemState`에 HLE file handle table을 추가했다. DOS standard handle `0..4`는 예약하고, 파일 open 성공 시 `5`부터 handle을 할당한다.

Win32 execution trampoline은 `INT 21h AH=0x3D`에서 `EDX`가 가리키는 ASCIZ path와 `AL` access mode를 읽고, 가상 current directory 기반 path resolver로 host path를 계산한다.

`piu_1st`에서는 `\DATAS\BGA` current directory에서 `intro.ani` open을 요청했다. 이는 `\DATAS\BGA\INTRO.ANI`로 해석되었지만 해당 host file이 없으므로 DOS error `0x0002`로 실패 처리되었다. 이 실패 처리 이후 실행은 `0x020FAA81`의 `INT 21h AH=0x44` IOCTL 요청까지 진행했다.

## 검증

다음 검증을 완료했다.

* `scripts\test_all.ps1`: 통과. `piu_1st`는 `INT 21h AH=0x3D` open 요청을 처리한 뒤 `0x020FAA81`의 `INT 21h AH=0x44` 지점까지 진행했다.
* `scripts\test_openwatcom_samples.ps1 -CompareBaseline`: 통과. 전체 819개 중 overall pass 470개, overall pass rate 57.4%, regression 0개, new pass 51개다.

# DOS File Open HLE Work Log

## Result

Added an HLE file handle table to `DosVirtualFileSystemState`. DOS standard handles `0..4` are reserved, and successful file opens allocate handles starting at `5`.

The Win32 execution trampoline now reads the ASCIZ path pointed to by `EDX` and the `AL` access mode for `INT 21h AH=0x3D`, then calculates the host path through the virtual current-directory path resolver.

In `piu_1st`, `intro.ani` is opened while the current directory is `\DATAS\BGA`. It resolves to `\DATAS\BGA\INTRO.ANI`, but that host file does not exist, so the request fails with DOS error `0x0002`. After this handled failure, execution advances to the `INT 21h AH=0x44` IOCTL request at `0x020FAA81`.

## Verification

Completed the following verification:

* `scripts\test_all.ps1`: passed. `piu_1st` handled the `INT 21h AH=0x3D` open request and advanced to the `INT 21h AH=0x44` stop at `0x020FAA81`.
* `scripts\test_openwatcom_samples.ps1 -CompareBaseline`: passed. Overall pass is 470 of 819, overall pass rate is 57.4%, regression count is 0, and new pass count is 51.
