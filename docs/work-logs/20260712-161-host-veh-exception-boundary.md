# Host VEH 예외 경계 작업 로그 / Work Log

## 한국어

Glide ordinal `0x76`은 `_GRSSTWINOPEN@28`로 확인했습니다. WGL 초기화 중 host 주소에서 발생한 `0x406D1388`을 Windows 예외 체인으로 전달하자 창 생성이 진행되고 이후 ordinal `0x5E`까지 실행되었습니다.

## English

Confirmed Glide ordinal `0x76` as `_GRSSTWINOPEN@28`. Passing host-side `0x406D1388` to the Windows exception chain allows WGL window creation and execution to continue through ordinal `0x5E`.
