# INT 21h AH=25h 인터럽트 벡터 설정 작업 로그

## 결과

DOS interrupt vector shadow를 추가했다. `AH=25h`는 `AL` vector 번호에 대해 현재 guest `DS:DX`를 저장하고 carry flag를 clear한다. 기존 `AH=35h`는 저장된 vector가 있으면 `ES:BX`로 반환하고, 없으면 `0000:0000`을 반환하도록 갱신했다.

일반 DOS interrupt handler와 traced DOS interrupt handler 양쪽에 `AH=25h` 처리를 추가했다.

## 관측

`piu_1st`는 기존 중단점인 `INT 21h AH=25h AL=09h`를 통과했다. 다음 중단점은 relocated base + `0x000F4221`의 `CD 21`이며, `EAX=0x00004700`이다.

이는 `INT 21h AH=47h`, 현재 디렉터리 조회 요청이다. 직전까지 interrupt 09h vector 조회/설정 흐름이 처리되었고, 이제 파일/경로 관련 DOS HLE가 다음 후보가 되었다.

## 검증

* 통과: `cmd /c scripts\build_win32_x86.bat`
* 통과: `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* 통과: `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1 -SkipSetup`
* 참고: Win32 x86 빌드 중 서드파티 `spdlog` 헤더의 기존 `C4819` 경고가 출력되었다.

# INT 21h AH=25h Set Vector Work Log

## Result

A DOS interrupt vector shadow was added. `AH=25h` stores the current guest `DS:DX` for the `AL` vector number and clears carry flag. The existing `AH=35h` handling now returns a stored vector through `ES:BX` when present, or `0000:0000` when absent.

`AH=25h` handling was added to both the normal DOS interrupt handler and the traced DOS interrupt handler.

## Observation

`piu_1st` passed the previous `INT 21h AH=25h AL=09h` blocker. The next blocker is `CD 21` at relocated base + `0x000F4221`, with `EAX=0x00004700`.

This is `INT 21h AH=47h`, a get current directory request. The interrupt 09h vector query/set flow is now handled, and file/path-related DOS HLE is the next candidate.

## Verification

* Passed: `cmd /c scripts\build_win32_x86.bat`
* Passed: `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* Passed: `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1 -SkipSetup`
* Note: The Win32 x86 build still emits the existing third-party `spdlog` header `C4819` warning.
