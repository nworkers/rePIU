# 20260809-450 CHD cooked Mode 1 ISO9660 지원 작업 로그 / CHD Cooked Mode 1 ISO9660 Support Work Log

설계: [20260809-450-chd-cooked-mode1-iso9660.md](../design/20260809-450-chd-cooked-mode1-iso9660.md)
작업 지시: [20260809-450-chd-cooked-mode1-iso9660.md](../work-orders/20260809-450-chd-cooked-mode1-iso9660.md)

## 한국어

### 결과

- CHT2/CHTR의 `TYPE`을 `ChdCdTrackType`으로 보존하고 cooked/raw sector별 ISO9660
  user-data offset을 명시적으로 선택했습니다.
- 기존 sector byte 15 휴리스틱을 제거하고 미지원 data track 형식은 fail-closed 처리했습니다.
- 사용자 요청에 따라 임시 `ResolvePiuExecutable()` 변경은 롤백하고 기존
  `PIU/PIU.EXE` 및 `PIU` 작업 디렉터리 정책을 유지했습니다.
- 현재 `pumpito` CHD를 `chdman verify`와 `extractcd`로 재검증했습니다. 복원한
  `MODE1/2048` 이미지와 로컬 ISO의 SHA-256이 일치했습니다.

### 검증

- `cmake --build build\\win32_x86_debug --config Debug`: 성공. 기존 C4819 경고만 발생했습니다.
- `repiu_chd_cd_probe roms\\pumpito\\OBGSE.chd --metadata`: 단일 `MODE1`, 68,568 frames 확인.
- `repiu_exe_analyzer pumpito`: 성공. `PIU/PIU.EXE`, 4개 LE object, relocation failure 0건.
- `repiu_exe_analyzer pumpit1`, `pumpit2`, `pumpit3`, `pumpite`: 모두 exit code 0.
- `chdman verify`: raw SHA-1 및 overall SHA-1 검증 성공.
- `chdman extractcd`: 복원 이미지와 `OBGSE.iso` SHA-256 일치.

## English

### Result

- Preserved CHT2/CHTR `TYPE` as `ChdCdTrackType` and selected explicit ISO9660 user-data offsets
  for cooked and raw sector layouts.
- Removed the sector-byte-15 heuristic and made unsupported data-track formats fail closed.
- Rolled back the temporary `ResolvePiuExecutable()` change at the user's request, preserving the
  existing `PIU/PIU.EXE` executable and `PIU` working-directory policy.
- Reverified the current `pumpito` CHD with `chdman verify` and `extractcd`. The restored
  `MODE1/2048` image has the same SHA-256 as the local ISO.

### Verification

- `cmake --build build\\win32_x86_debug --config Debug`: passed with existing C4819 warnings only.
- `repiu_chd_cd_probe roms\\pumpito\\OBGSE.chd --metadata`: one `MODE1` track, 68,568 frames.
- `repiu_exe_analyzer pumpito`: passed with `PIU/PIU.EXE`, four LE objects, and zero relocation failures.
- `repiu_exe_analyzer pumpit1`, `pumpit2`, `pumpit3`, and `pumpite`: all exited with code 0.
- `chdman verify`: raw SHA-1 and overall SHA-1 verification passed.
- `chdman extractcd`: the restored image and `OBGSE.iso` SHA-256 values match.
