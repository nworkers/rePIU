# 20260725-293-lfb-bmp-dump

## 작업 목표 (Objective)
- `grLfbUnlock` 시점에 Guest가 LFB에 쓴 픽셀 데이터를 디버깅 목적으로 BMP 파일로 덤프하는 기능 추가.

## 변경 사항 (Changes)
- `src/platform/win32/boundary/linexe_glide_boundary.cpp` 수정
  - `_GRLFBUNLOCK@8` 핸들러 내부에 `REPIU_DUMP_LFB_BMP=1` 환경 변수가 설정되어 있을 경우, `DecodeGlideLfb565ToRgba8`로 변환된 RGBA 데이터를 `DumpTextureToBmp` 함수를 통해 BMP 파일로 저장하도록 코드를 추가했습니다.
  - 저장된 파일은 기존 텍스처 덤프와 동일하게 `build/texture_dumps/` 경로에 생성됩니다.

## 검증 (Verification)
- 코드가 정상적으로 컴파일되는 것을 확인 (`cmake --build build --config Release`).
- 기존 텍스처 덤프 함수인 `DumpTextureToBmp`를 재사용하여 안전성을 확보함.
