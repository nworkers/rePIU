# INT 21h AH=0xED HLE 작업 로그

## 변경 내용

trace 기반 `HandleTracedDosInterrupt21`에 `AH=0xED` 처리를 추가했다. 응답은 기존 일반 DOS HLE 경로와 같은 최소 규칙을 사용한다.

* `AL = 0`
* carry flag clear
* `EIP += 2`
* 마지막 DOS interrupt 기록을 `0x21 / AH=0xED`로 갱신

## 검증 결과

`scripts\test_all.ps1`에서 빌드, `dos4gw_hello`, `piu_1st` 실행이 통과했다. `piu_1st`는 이전 `0x020FBAF8`의 `INT 21h AH=0xED`를 통과했다.

새 정지점은 `0x020FBB24`의 `CD 21`이다. 직전 byte pattern은 `B4 4A CD 21`이고 예외 시점 `EAX=0x00004A2B`이므로, 다음 작업은 `INT 21h AH=0x4A` 메모리 블록 resize 계열 처리를 분석하는 것이다.

`scripts\test_openwatcom_samples.ps1 -CompareBaseline`도 통과했다. 전체 819개 샘플 중 pass는 419개로 유지되었고, baseline 대비 회귀는 0건이다.

# INT 21h AH=0xED HLE Work Log

## Changes

Added `AH=0xED` handling to the trace-based `HandleTracedDosInterrupt21`. The response uses the same minimal rule as the existing general DOS HLE path.

* `AL = 0`
* clear carry flag
* `EIP += 2`
* record the last DOS interrupt as `0x21 / AH=0xED`

## Verification Result

`scripts\test_all.ps1` passed the build, `dos4gw_hello`, and `piu_1st` runs. `piu_1st` passed the previous `INT 21h AH=0xED` at `0x020FBAF8`.

The new stop is `CD 21` at `0x020FBB24`. The preceding byte pattern is `B4 4A CD 21`, and exception-time `EAX=0x00004A2B`, so the next task is to analyze `INT 21h AH=0x4A`, the DOS memory block resize service family.

`scripts\test_openwatcom_samples.ps1 -CompareBaseline` also passed. Across all 819 samples, the pass count remains 419 and baseline regressions are 0.
