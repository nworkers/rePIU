# Win32 x86 빌드 구성 작업 로그

## 결과

Win32 x86 CMake 빌드 스크립트를 추가했다.

`scripts/build_win32_x86.bat`는 `Visual Studio 17 2022` generator와 `Win32` platform을 사용해 `build\vs2022_win32_debug` 구성을 생성하고 Debug 빌드를 수행한다.

32-bit analyzer 실행 결과 host pointer bits가 32로 보고되고, direct x86 execution이 supported로 보고되는 것을 확인했다.

이번 단계에서는 원본 entry 호출, 실행 메모리 할당, HLE 호출을 추가하지 않았다.

## 검증

Win32 x86 빌드:

```text
cmd /c scripts\build_win32_x86.bat
```

결과:

```text
repiu_exe.lib 빌드 성공
repiu_exe_analyzer.exe 빌드 성공
```

Win32 analyzer 실행:

```text
build\vs2022_win32_debug\Debug\repiu_exe_analyzer.exe
```

주요 출력:

```text

Win32 host pointer bits: 32
Win32 direct x86 execution: supported
Win32 preferred allocation base: 0x00010000
Win32 required reserve size: 0x005D7000
Win32 HLE reserve base: 0x005E7000
Win32 memory policy message: 32-bit host process can transfer control to original x86 code
Runtime memory dry run: valid
LE relocation dry run: valid
LE applied relocations: 14637
LE failed relocations: 0
LE skipped relocations: 10
```

## Result

Added a Win32 x86 CMake build script.

`scripts/build_win32_x86.bat` uses the `Visual Studio 17 2022` generator with the `Win32` platform to generate `build\vs2022_win32_debug` and build Debug.

The 32-bit analyzer reports host pointer bits as 32 and direct x86 execution as supported.

This step does not add original entry calls, executable memory allocation, or HLE calls.
