# 작업 로그: GitHub Actions의 Node.js 20 런타임 교체 (issue #50)

작업 지시: `docs/work-orders/20261010-i050-actions-node24.md`

## 한 일

`ci.yml`, `release.yml`, `pages.yml`에서 `actions/checkout@v4`→`v7`(6곳), `actions/cache@v4`→`v6`(3곳),
`actions/upload-artifact@v4`→`v7`(2곳), `actions/download-artifact@v4`→`v8`(1곳). 각 메이저의
`action.yml`이 `node24`임을 확인했고(`upload-artifact`·`download-artifact` v5는 아직 `node20`이라 v6 이상이
필요), 릴리스 노트상 이 저장소가 쓰는 입력(`path`, `pattern`, `merge-multiple`, `if-no-files-found`,
`retention-days`)에 영향을 주는 변경은 없다. `download-artifact@v8`은 다이제스트 불일치를 오류로 처리한다.
`configure-pages@v6`, `deploy-pages@v5`, `setup-python@v7`는 이미 `node24`, `upload-pages-artifact@v5`는
내부에서 `upload-artifact@v7`을 쓴다.

**Done.** In `ci.yml`, `release.yml` and `pages.yml`: `actions/checkout@v4`→`v7` (six places),
`actions/cache@v4`→`v6` (three), `actions/upload-artifact@v4`→`v7` (two), `actions/download-artifact@v4`→`v8`

mismatch. `configure-pages@v6`, `deploy-pages@v5` and `setup-python@v7` already read `node24`, and
`upload-pages-artifact@v5` uses `upload-artifact@v7` inside.

**Verified.** A manual `release.yml` run on the branch (38044904199): the Linux x64 and i386 jobs pass,
artifacts upload through `upload-artifact@v7`, and no Node.js 20 warning appears. PR #49's CI (`ci.yml`,
Win32, run 38044907739) passes with `checkout@v7` and `cache@v6` and no Node.js 20 warning.

**Not checked.** `download-artifact@v8` and the `publish` job run on tag runs only and are checked by the
