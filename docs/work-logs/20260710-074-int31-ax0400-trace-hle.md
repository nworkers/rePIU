# INT 31h AX=0400h trace HLE 작업 로그

## 요약

`piu_1st`가 `INT 2Fh AX=1686h` 이후 도달한 `INT 31h AX=0400h`를 trace 경로에서도 처리하도록 연결했다.

기존 일반 HLE 경로에는 `HandleDpmiInterrupt31`의 `AX=0400h` 최소 응답이 이미 있었지만, single-step trace pre-handler는 `INT 21h`와 `INT 2Fh`만 먼저 확인했다. 따라서 trace 실행 중 `CD 31`이 일반 HLE dispatch에 도달하지 못하고 예외 관측 지점으로 남았다.

## 변경 내용

* `HandleTracedDpmiInterrupt31`을 추가했다.
* single-step trace와 vectored exception pre-handler에서 `INT 31h` trace handler를 호출하도록 했다.
* `HandleDpmiInterrupt31`의 `AX=0400h` 처리 시 마지막 interrupt vector/AX 진단 정보를 기록하도록 했다.
* `scripts/test_all.ps1`의 `piu_1st` 기대 관측 지점을 `INT 33h` blocker로 갱신했다.

## 결과

`INT 31h AX=0400h`는 처리되었고, `piu_1st`는 다음 관측 지점으로 진행했다.

새 관측 지점:

* exception address: `0x020F9697`
* exception bytes: `CD 33`
* last handled interrupt vector: `0x31`
* last handled interrupt AX: `0x0400`
* console output: `FAIL: res_load( spr.res )`

`spr.res` 파일이 없는 것은 현재 자산 상태에서 정상으로 확인된 조건이다. 따라서 다음 작업은 `INT 33h` mouse interrupt 계열을 어떤 최소 HLE 정책으로 응답할지 설계하는 것이다.

## 검증

* `cmd /c scripts\build_win32_x86.bat`
  * 통과
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
  * 확인: `INT 31h AX=0400h` 처리 후 `INT 33h` blocker 도달
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1`
  * 통과

# INT 31h AX=0400h Trace HLE Work Log

## Summary

Connected `INT 31h AX=0400h`, reached by `piu_1st` after `INT 2Fh AX=1686h`, to the trace path.

The general HLE path already had the minimal `AX=0400h` response in `HandleDpmiInterrupt31`, but the single-step trace pre-handler only checked `INT 21h` and `INT 2Fh`. As a result, traced `CD 31` did not reach the general HLE dispatch and remained as the observed exception point.

## Changes

* Added `HandleTracedDpmiInterrupt31`.
* Called the `INT 31h` trace handler from the single-step trace and vectored exception pre-handlers.
* Recorded last interrupt vector/AX diagnostics when handling `AX=0400h` in `HandleDpmiInterrupt31`.
* Updated the `piu_1st` expected observation point in `scripts/test_all.ps1` to the `INT 33h` blocker.

## Result

`INT 31h AX=0400h` is now handled, and `piu_1st` progressed to the next observation point.

New observation point:

* exception address: `0x020F9697`
* exception bytes: `CD 33`
* last handled interrupt vector: `0x31`
* last handled interrupt AX: `0x0400`
* console output: `FAIL: res_load( spr.res )`

The missing `spr.res` file is an expected condition for the current asset state. Therefore, the next task is to design the minimal HLE policy for the `INT 33h` mouse interrupt family.
