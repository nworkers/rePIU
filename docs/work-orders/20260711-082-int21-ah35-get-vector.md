# INT 21h AH=35h 인터럽트 벡터 조회 작업 지시

## 목표

`piu_1st`가 `INT 21h AH=35h AL=09h`에서 중단되지 않도록 최소 DOS HLE 응답을 추가한다.

## 범위

* `AH=35h` 처리 helper를 추가한다.
* 일반 `HandleDosInterrupt21`에 `AH=35h` case를 추가한다.
* traced `HandleTracedDosInterrupt21`에 `AH=35h` case를 추가한다.
* 반환값은 `ES:BX = 0000:0000`, carry clear로 둔다.
* 실행 결과와 회귀 테스트 기대치를 새 중단점에 맞게 갱신한다.

## 검증

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1 -SkipSetup`

# INT 21h AH=35h Get Vector Work Order

## Goal

Add a minimal DOS HLE response so `piu_1st` does not stop at `INT 21h AH=35h AL=09h`.

## Scope

* Add an `AH=35h` handling helper.
* Add an `AH=35h` case to `HandleDosInterrupt21`.
* Add an `AH=35h` case to `HandleTracedDosInterrupt21`.
* Return `ES:BX = 0000:0000` with carry clear.
* Update the run result and regression test expectations to the new blocker.

## Verification

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1 -SkipSetup`
