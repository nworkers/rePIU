# DOS File Open HLE 작업 지시

## 목표

`INT 21h AH=0x3D`을 처리해 `piu_1st`가 file open 요청 이후의 다음 실행 지점까지 진행하게 한다.

## 작업 범위

* `DosVirtualFileSystemState`에 HLE file handle table을 추가한다.
* 기존 가상 current directory path resolver를 재사용해 open 대상 host path를 계산한다.
* `INT 21h AH=0x3D`에서 guest ASCIZ 경로를 읽고 파일 존재 여부를 확인한다.
* 성공 시 DOS handle을 `5`부터 할당하고 CF를 clear한다.
* 실패 시 DOS error code를 `AX`에 반환하고 CF를 set한다.
* loader 로그에 마지막 DOS open 요청, resolved host path, handle, 결과를 출력한다.
* `scripts\test_all.ps1`의 `piu_1st` 기대 지점을 새 중단 지점으로 갱신한다.

## 제외 범위

* `read/write/seek/close`는 구현하지 않는다.
* 파일 내용을 아직 host에서 읽어 보관하지 않는다.
* 공유 모드, deny mode, device file semantics는 구현하지 않는다.

* `scripts\test_openwatcom_samples.ps1 -CompareBaseline`

# DOS File Open HLE Work Order

## Goal

Handle `INT 21h AH=0x3D` so `piu_1st` can advance to the next execution point after the file open request.

## Scope

* Add an HLE file handle table to `DosVirtualFileSystemState`.
* Reuse the virtual current-directory path resolver to calculate the open target host path.
* Read the guest ASCIZ path for `INT 21h AH=0x3D` and check file existence.
* On success, allocate a DOS handle starting at `5` and clear CF.
* On failure, return a DOS error code in `AX` and set CF.
* Print the last DOS open request, resolved host path, handle, and result in loader logs.
* Update the `piu_1st` expectation in `scripts\test_all.ps1` to the new stop.

## Out of Scope

* Do not implement `read`, `write`, `seek`, or `close`.
* Do not read and store file contents yet.
* Do not implement sharing mode, deny mode, or device-file semantics.
