# INT 31h AX=0400h trace HLE 작업 지시

## 목표

`piu_1st`가 `INT 2Fh AX=1686h` 이후 도달한 `INT 31h AX=0400h`를 trace 경로에서도 기존 DPMI HLE로 처리한다.

## 범위

* `src/platform/win32/execution_trampoline.cpp`
  * trace pre-handler에 `INT 31h` 감지 함수를 추가한다.
  * 기존 `HandleDpmiInterrupt31`로 위임한다.
  * `AX=0400h` 처리 시 마지막 interrupt vector/AX 진단 정보를 기록한다.
* `scripts/test_all.ps1`
  * `piu_1st`의 현재 기대 관측 지점을 새 blocker로 갱신한다.

## 제외

* 새로운 DPMI 함수 의미 구현
* descriptor/state save/restore의 실제 버퍼 모델링
* 원본 실행 파일 코드 수정

## 검증

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1`

# INT 31h AX=0400h Trace HLE Work Order

## Goal

Handle `INT 31h AX=0400h`, reached by `piu_1st` after `INT 2Fh AX=1686h`, through the trace path using the existing DPMI HLE.

## Scope

* `src/platform/win32/execution_trampoline.cpp`
  * Add an `INT 31h` detector to the trace pre-handler.
  * Delegate to the existing `HandleDpmiInterrupt31`.
  * Record the last interrupt vector/AX diagnostics when handling `AX=0400h`.
* `scripts/test_all.ps1`
  * Update the current expected `piu_1st` observation point to the new blocker.

## Excluded

* Implementing new DPMI function semantics
* Modeling real descriptor or state save/restore buffers
* Modifying original executable code

## Verification

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1`
