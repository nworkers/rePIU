# INT 21h AH=0xED HLE 작업 지시

## 목표

`piu_1st`가 `INT 21h AH=0xED`에서 멈추지 않고 최소 DOS HLE 응답 후 다음 관측 지점까지 진행하게 한다.

## 작업 범위

* trace 기반 `HandleTracedDosInterrupt21`에 `AH=0xED` 처리를 추가한다.
* 응답은 `AL=0`, CF clear, `EIP += 2`로 제한한다.
* `test_all.ps1`의 `piu_1st` 기대 관측점을 새 정지점으로 갱신한다.
* 작업 로그에 새 정지점과 검증 결과를 기록한다.

## 제외 범위

* `INT 21h AH=0xED`의 전체 의미를 확정하지 않는다.
* 전체 DOS HLE를 `piu_1st` 경로에 켜지 않는다.
* 다른 미관측 `INT 21h` 함수는 추가하지 않는다.

## 검증

* `scripts\test_all.ps1`
* `scripts\test_openwatcom_samples.ps1 -CompareBaseline`

# INT 21h AH=0xED HLE Work Order

## Goal

Allow `piu_1st` to continue past `INT 21h AH=0xED` by applying a minimal DOS HLE response and reaching the next observed point.

## Scope

* Add `AH=0xED` handling to the trace-based `HandleTracedDosInterrupt21`.
* Limit the response to `AL=0`, clear CF, and `EIP += 2`.
* Update the `piu_1st` expected observation point in `test_all.ps1`.
* Record the new stop and verification result in the work log.

## Out of Scope

* Do not finalize the full meaning of `INT 21h AH=0xED`.
* Do not enable the full DOS HLE path for `piu_1st`.
* Do not add other unobserved `INT 21h` functions.
