# INT 21h AH=0x30 HLE 작업 지시

## 목표

`piu_1st`가 `INT 21h AH=0x30`에서 멈추지 않고, DOS version query HLE 처리 후 다음 명령으로 계속 진행하게 한다.

## 범위

1. Win32 execution trampoline에 DOS version query HLE 플래그를 추가한다.
2. `INT 21h AH=0x30` 처리 경로를 `piu_1st` trap 실행 경로에 연결한다.
3. execution attempt에 처리된 DOS interrupt count와 마지막 vector/AH를 기록한다.
4. loader 로그에 해당 값을 출력한다.
5. `piu_1st`와 `dos4gw_hello`를 검증한다.
6. TODO와 작업 로그를 갱신한다.

## 제외

* `INT 21h` 전체 구현은 하지 않는다.
* `INT 31h` DPMI 구현은 다음 작업으로 둔다.
* DOS memory access HLE를 `piu_1st`에 일반적으로 켜지 않는다.

# INT 21h AH=0x30 HLE Work Order

## Goal

Allow `piu_1st` to continue past `INT 21h AH=0x30` by handling DOS version query through HLE.

## Scope

1. Add a DOS version query HLE flag to the Win32 execution trampoline.
2. Wire `INT 21h AH=0x30` handling into the `piu_1st` trap execution path.
3. Record handled DOS interrupt count and the last vector/AH in the execution attempt.
4. Print those values in loader diagnostics.
5. Verify `piu_1st` and `dos4gw_hello`.
6. Update TODO and the work log.

## Out Of Scope

* Do not implement all `INT 21h` services.
* Leave `INT 31h` DPMI implementation for a later task.
* Do not generally enable DOS memory access HLE for `piu_1st`.
