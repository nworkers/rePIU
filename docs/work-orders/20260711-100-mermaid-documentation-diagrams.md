# 분석·지식 문서 Mermaid 도식 작업 지시

## 작업

1. analysis/kb README에 문서 탐색 map을 추가한다.
2. 각 주제 문서의 핵심 흐름이나 관계에 적합한 Mermaid diagram을 추가한다.
3. diagram이 본문의 확인 상태와 모순되지 않는지 대조한다.
4. Mermaid fence와 local Markdown link를 정적 검증한다.
5. 작업 로그를 작성하고 변경을 커밋한다.

# Mermaid Diagram Work Order for Analysis and Knowledge Documents

## Tasks

1. Add document-navigation maps to the analysis and knowledge README files.

3. Check every diagram against the confirmation status in the prose.
4. Statically validate Mermaid fences and local Markdown links.
5. Write the work log and commit the change.
