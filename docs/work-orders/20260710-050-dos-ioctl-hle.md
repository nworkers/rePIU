# DOS IOCTL HLE 작업 지시

## 목표

`piu_1st`가 `INT 21h AH=0x44 AL=0x00` stdout 장치 정보 조회를 통과하도록 traced DOS HLE에 최소 IOCTL 처리를 추가한다.

## 작업 범위

* DOS 파일 시스템 HLE에 열린 handle 조회 함수를 추가한다.
* traced DOS interrupt 처리에 `AH=0x44 AL=0x00` 분기를 추가한다.
* 표준 handle `0..4`는 character device로 응답한다.
* 열린 파일 handle은 disk file로 응답한다.
* 알 수 없는 handle은 DOS invalid handle 오류 `0x0006`으로 실패시킨다.
* 실행 로그에 마지막 IOCTL subfunction, handle, 결과, device info를 출력한다.
* `scripts\test_all.ps1`의 `piu_1st` 기대 관측 지점을 갱신한다.

## 제외 범위

* 다른 IOCTL subfunction은 구현하지 않는다.
* 실제 콘솔/파일 read, write, seek, close 처리는 이번 작업에 포함하지 않는다.
* DOS 장치 attribute bit 전체를 정밀하게 모델링하지 않는다.

## 검증

* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `scripts\test_all.ps1`

# DOS IOCTL HLE Work Order

## Goal

Add minimum traced DOS HLE handling for `INT 21h AH=0x44 AL=0x00` so `piu_1st` can pass its stdout device information query.

## Scope

* Add an open-handle lookup helper to the DOS filesystem HLE.
* Add an `AH=0x44 AL=0x00` branch to traced DOS interrupt handling.
* Return standard handles `0..4` as character devices.
* Return open file handles as disk files.
* Fail unknown handles with DOS invalid handle error `0x0006`.
* Print the last IOCTL subfunction, handle, result, and device info in execution logs.
* Update the `piu_1st` expected observation point in `scripts\test_all.ps1`.

## Out of Scope

* Do not implement other IOCTL subfunctions.
* Do not implement actual console/file read, write, seek, or close behavior in this task.
* Do not fully model all DOS device attribute bits.

## Verification

* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `scripts\test_all.ps1`
