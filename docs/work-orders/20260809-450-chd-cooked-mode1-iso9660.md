# 20260809-450 CHD cooked Mode 1 ISO9660 지원 작업 지시 / CHD Cooked Mode 1 ISO9660 Support Work Order

## 한국어

### 목표

CHD track metadata에 따라 ISO9660 user-data offset을 결정하여 `pumpito`의 cooked `MODE1`
CHD를 지원하고 기존 raw Mode 2 자산을 보존합니다.

### 작업 항목

- [x] `ChdCdTrackType`과 CHT2/CHTR type parsing을 공용 CHD image 계층에 추가합니다.
- [x] ISO reader가 track type별 offset을 사용하고 미지원 형식을 fail-closed하도록 변경합니다.
- [x] 관련 아키텍처와 CD sector 지식 문서를 갱신합니다.
- [x] `pumpito` 누적 분석 문서와 분석 색인을 추가합니다.
- [x] 전체 Win32 x86 Debug 빌드, `pumpito`, 기존 네 raw 자산 회귀를 검증합니다.
- [x] 작업 로그를 작성하고 하나의 Git 커밋으로 남깁니다.

## English

### Objective

Resolve the ISO9660 user-data offset from CHD track metadata, supporting `pumpito`'s cooked
`MODE1` CHD while preserving existing raw Mode 2 assets.

### Work Items

- [x] Add `ChdCdTrackType` and CHT2/CHTR type parsing to the shared CHD image layer.
- [x] Make the ISO reader use type-specific offsets and fail closed on unsupported formats.
- [x] Update the relevant architecture and CD-sector knowledge documentation.
- [x] Add cumulative `pumpito` analysis and its analysis index entry.
- [x] Verify the full Win32 x86 Debug build, `pumpito`, and the four existing raw assets.
- [x] Write the work log and leave one Git commit.
