# INT 21h AH=25h 인터럽트 벡터 설정 작업 지시

## 목표

`piu_1st`가 `INT 21h AH=25h AL=09h`에서 중단되지 않도록 DOS interrupt vector shadow를 추가한다.

## 범위

* `ThreadContext`에 256-entry interrupt vector shadow를 추가한다.
* `AH=25h` 처리 helper를 추가한다.
* 기존 `AH=35h` helper가 shadow를 반환하도록 갱신한다.
* 일반/traced `INT 21h` 처리기에 `AH=25h` case를 추가한다.
* 실행 결과와 테스트 기대치를 새 중단점에 맞게 갱신한다.

## 검증

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1 -SkipSetup`

# INT 21h AH=25h Set Vector Work Order

## Goal

Add a DOS interrupt vector shadow so `piu_1st` does not stop at `INT 21h AH=25h AL=09h`.

## Scope

* Add a 256-entry interrupt vector shadow to `ThreadContext`.
* Add an `AH=25h` handling helper.
* Update the existing `AH=35h` helper to return shadowed vectors.
* Add an `AH=25h` case to both normal and traced `INT 21h` handling.
* Update the run result and test expectations to the new blocker.

## Verification

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1 -SkipSetup`
