# PIU 장기 실행 관찰 작업 지시 / Work Order

## 한국어

1. PIU 실행 제한을 120초로 늘린다.
2. live telemetry와 최종 관찰 로그를 수집한다.
3. 반복 실행 주소와 새 오류·종료·Glide 경계를 분류한다.
4. 확인 결과를 analysis와 작업 로그에 반영한다.

## English

1. Extend the PIU execution limit to 120 seconds.
2. Capture live telemetry and the final observation report.
3. Classify recurring execution addresses and any new error, termination, or Glide boundary.
4. Record confirmed findings in analysis and the work log.
