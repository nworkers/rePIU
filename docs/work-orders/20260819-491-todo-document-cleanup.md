# Task 491 TODO Document Cleanup Work Order

Design: [20260819-491-todo-document-cleanup.md](../design/20260819-491-todo-document-cleanup.md)

1. Compare every `docs/TODO.md` entry against current work logs and analysis.
2. Remove completed setter/batching, `0x02A0`, and July bootstrap records from the
   active list.
3. State that there are no current active TODO entries and retain closure links.
4. Document the roles of the global TODO, frontier, work orders, and work logs.
5. Validate relative links, bilingual correspondence, and Markdown formatting.
6. Record the cleanup in a work log and commit it.

## Completion Criteria

- `docs/TODO.md` represents only genuinely unfinished items.
- Removed history remains traceable through representative evidence documents.
- The absence of active TODO entries is immediately clear.
