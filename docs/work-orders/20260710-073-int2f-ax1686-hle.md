# INT 2Fh AX=1686h HLE 작업 지시

## 목표

`piu_1st`가 runtime arena 확장 이후 도달한 `INT 2Fh AX=1686h`를 trace 경로에서도 최소 HLE로 처리한다.

## 범위

* trace interrupt pre-handler에 `INT 2Fh` 처리를 추가한다.
* `AX=1686h`에 대해 Windows enhanced mode / external DPMI host 비활성 응답을 돌려준다.
* 마지막 DOS interrupt AX 관측 필드를 추가하고 loader/test를 갱신한다.
* 다음 blocker를 `piu_1st` 실행으로 확인한다.

## 검증

* `cmd /c scripts\build_win32_x86.bat`
* `build\win32_x86_debug\Debug\repiu_loader_win32.exe piu_1st`
* `powershell -ExecutionPolicy Bypass -File scripts\test_all.ps1`

# INT 2Fh AX=1686h HLE Work Order

## Goal

Handle `INT 2Fh AX=1686h`, reached by `piu_1st` after runtime arena expansion, through the trace path with minimal HLE.

## Scope

* Add `INT 2Fh` handling to the trace interrupt pre-handler.
* Return Windows enhanced mode / external DPMI host inactive for `AX=1686h`.
* Add last DOS interrupt AX observation and update loader/tests.
* Run `piu_1st` to identify the next blocker.
