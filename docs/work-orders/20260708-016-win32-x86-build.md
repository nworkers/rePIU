# Win32 x86 빌드 구성 작업 지시

원본 32-bit x86 코드 직접 실행 준비를 위해 Win32 x86 빌드 스크립트와 검증 절차를 추가한다.

## 작업 범위

* `scripts/build_win32_x86.bat` 추가
* Win32 CMake build directory 정책 문서화
* Win32 analyzer 실행 검증
* `ARCHITECTURE.md`, `docs/PROJECT_CHARTER.md` 갱신

## 제외 범위

* 원본 entry 호출
* 실행 메모리 할당
* HLE 호출

## 검증 절차

1. `scripts\build_win32_x86.bat`를 실행한다.
2. `build\vs2022_win32_debug\Debug\repiu_exe_analyzer.exe`를 실행한다.
3. `Win32 host pointer bits: 32`와 `Win32 direct x86 execution: supported`를 확인한다.

## Work Order

Add a Win32 x86 build script and verification procedure to prepare for direct original 32-bit x86 execution.

## Scope

* Add `scripts/build_win32_x86.bat`.
* Document the Win32 CMake build directory policy.
* Verify the Win32 analyzer run.
* Update `ARCHITECTURE.md` and `docs/PROJECT_CHARTER.md`.

## Out of Scope

* Calling the original entry point.
* Allocating executable memory.
* HLE calls.

## Verification Procedure

1. Run `scripts\build_win32_x86.bat`.
2. Run `build\vs2022_win32_debug\Debug\repiu_exe_analyzer.exe`.
3. Confirm `Win32 host pointer bits: 32` and `Win32 direct x86 execution: supported`.
