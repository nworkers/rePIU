# INT 21h AH=0xFF HLE 작업 지시

## 목표

`piu_1st`가 `INT 21h AH=0xFF`에서 멈추지 않고, 최소 DOS HLE 응답 후 다음 명령으로 계속 진행하게 한다.

## 범위

1. trace 기반 DOS HLE 경로에서 `AH=0x30`과 `AH=0xFF`를 함께 처리한다.
2. `AH=0xFF` 처리 시 `AL=0`, carry clear, `EIP += 2`를 적용한다.
3. 처리된 DOS interrupt count와 마지막 vector/AH 기록을 유지한다.
4. `piu_1st`와 `dos4gw_hello`를 검증한다.
5. TODO와 작업 로그를 갱신한다.

## 제외

* `AH=0xFF`의 최종 의미를 확정하지 않는다.
* `INT 21h` 전체 구현은 하지 않는다.
* `INT 31h` DPMI 구현은 다음 작업으로 둔다.

# INT 21h AH=0xFF HLE Work Order

## Goal

Allow `piu_1st` to continue past `INT 21h AH=0xFF` by applying a minimal DOS HLE response.

## Scope

1. Handle both `AH=0x30` and `AH=0xFF` in the trace-based DOS HLE path.
2. For `AH=0xFF`, apply `AL=0`, clear carry, and `EIP += 2`.
3. Preserve handled DOS interrupt count and last vector/AH recording.
4. Verify `piu_1st` and `dos4gw_hello`.
5. Update TODO and the work log.

## Out Of Scope

* Do not finalize the meaning of `AH=0xFF`.
* Do not implement all `INT 21h` services.
* Leave `INT 31h` DPMI implementation for a later task.
