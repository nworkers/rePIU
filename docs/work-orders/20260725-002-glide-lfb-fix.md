# Work Order: Glide LFB 기능 개선 (Loader Hang/Black Screen 해결)

## 개요 / Overview
**목적**: PIU 구버전 로더나 비디오 재생 시 LFB(Linear Frame Buffer) 기능이 호출될 때 무한 루프(Hang)에 빠지거나 검은 화면이 출력되는 현상을 해결한다.
**증상**: `grLfbLock`에 `GR_LFB_FRONTBUFFER`를 요청하거나, `grLfbWriteRegion` 등의 기능이 미처리(FXFALSE 반환)될 경우 게임이 대기 상태에 빠지며 멈춘다. 또한 프론트 버퍼 잠금 시 화면 갱신이 누락되어 검은 화면이 남는다.

## 작업 항목 / Task Items
1. **상수 정의 추가 (`include/repiu/hle/glide_lfb.h`)**
   - `kGlideLfbSrcFmt565 = 1` 등 픽셀 포맷 상수 추가.
2. **Region 업데이트 로직 구현 (`src/hle/glide_lfb.h` & `src/hle/glide_lfb.cpp`)**
   - `WriteRegionToGlideLfb565`: 외부 배열(src_data)을 lfb_surface 픽셀 버퍼 특정 위치에 복사.
3. **프론트 버퍼 화면 출력 대응 (`glide_opengl_backend`)**
   - `PresentLfbSurface`에 `present_to_front` 플래그를 추가하고 `true`일 경우 `SwapBuffers(0)` 즉시 호출.
4. **Boundary 핸들러 로직 갱신 (`linexe_glide_boundary.cpp`)**
   - `_GRLFBLOCK@24`: `kGlideBufferFrontBuffer`도 허용하도록 조건 완화.
   - `_GRLFBUNLOCK@8`: 해제 시 lock buffer가 프론트 버퍼라면 `present_to_front = true`를 줘서 화면 갱신.
   - `_GRLFBWRITEREGION@32`: 명시적 핸들러를 구현하여 LFB 특정 영역 업데이트 및 디코딩 후 Present 처리.
   - `_GRLFBREADREGION@28`, `_GRLFBCONSTANTALPHA@4`, `_GRLFBCONSTANTDEPTH@4`, `_GRLFBWRITECOLORSWIZZLE@8`: 우선 `FXTRUE`(또는 void 리턴)로 처리하는 더미 핸들러 추가하여 무한 루프 회피.

## 제약 사항 / Constraints
- 32-bit x86 레거시 ABI와 스택 정리(ESP 조정)를 철저히 지킨다.
- `grLfbWriteRegion`은 `src_format`이 565일 경우만 우선 대응하고, 그 외 포맷은 무시하되 `FXTRUE`를 반환해 로더 진행을 방해하지 않는다.
