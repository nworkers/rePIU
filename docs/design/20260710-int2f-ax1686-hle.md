# INT 2Fh AX=1686h HLE 설계

## 배경

runtime arena slack 확장 이후 `piu_1st`는 shadow memory 경로를 벗어나 다음 blocker인 `CD 2F`에 도달했다. 관측된 레지스터는 `EAX=0x00001686`이며, 이는 DOS multiplex interrupt `INT 2Fh AX=1686h` 호출이다.

현재 일반 DOS HLE 경로에는 `HandleDosInterrupt2F`가 있고 `AX=1686h`에 대한 최소 응답도 존재한다. 그러나 `piu_1st`의 single-step trace 경로는 pre-handler에서 `HandleTracedDosInterrupt21`만 호출하므로 `CD 2F`가 trace 단계에서 처리되지 못하고 예외로 떨어진다.

## 정책

`INT 2Fh AX=1686h`는 우선 Windows enhanced mode / external DPMI host 비활성으로 응답한다. 이 정책은 “guest code가 32-bit로 실행 중인가”와 “Windows/DPMI multiplex service를 제공하는가”를 분리한다.

응답은 기존 일반 HLE의 최소 응답과 맞춘다.

* `AX=0000h`
* `EIP += 2`

## 설계

* trace 경로에 `HandleTracedDosInterrupt2F`를 추가한다.
* 기존 `HandleDosInterrupt2F`도 동일 관측 기록을 남기도록 한다.
* interrupt 관측에는 마지막 vector, AH뿐 아니라 AX도 기록한다.
* loader는 마지막 DOS interrupt AX를 출력한다.

## 범위 밖

* Windows enhanced mode 또는 DPMI host 전체를 지원하지 않는다.
* `INT 2Fh`의 다른 AX function은 이번 작업에서 처리하지 않는다.
* 기대와 다르게 다음 경로가 host 지원을 요구할 경우 별도 작업에서 지원 응답과 추가 HLE를 설계한다.

# INT 2Fh AX=1686h HLE Design

## Background

After expanding runtime arena slack, `piu_1st` moved past the shadow memory path and reached the next blocker, `CD 2F`. The observed register state is `EAX=0x00001686`, which is DOS multiplex interrupt `INT 2Fh AX=1686h`.

The general DOS HLE path already has `HandleDosInterrupt2F` and a minimal `AX=1686h` response. However, the `piu_1st` single-step trace path calls only `HandleTracedDosInterrupt21` as a pre-handler, so `CD 2F` is not handled during trace execution and falls through as an exception.

## Policy

Initially respond to `INT 2Fh AX=1686h` as Windows enhanced mode / external DPMI host inactive. This separates “the guest code is running as 32-bit code” from “the host provides Windows/DPMI multiplex services.”

The response matches the existing general HLE minimum:

* `AX=0000h`
* `EIP += 2`

## Design

* Add `HandleTracedDosInterrupt2F` to the trace path.
* Make the existing `HandleDosInterrupt2F` record the same observation.
* Record the last interrupt AX in addition to vector and AH.
* Print the last DOS interrupt AX in the loader.

## Out Of Scope

* Do not support full Windows enhanced mode or a full DPMI host.
* Do not handle other `INT 2Fh` AX functions in this task.
* If the next path requires host support, design the supported response and additional HLE separately.
