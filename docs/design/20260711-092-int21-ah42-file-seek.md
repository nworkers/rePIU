# INT 21h AH=42h 파일 seek HLE 설계

`piu_1st`는 `AH=3Fh` 파일 읽기를 통과한 뒤 relocated base + `0x000F79D4`의 `CD 21`에서 중단된다. 예외 시점의 `EAX=0x00004201`, `EBX=0x00000005`, `ECX=0`, `EDX=0`이므로 이 호출은 DOS `INT 21h AH=42h AL=01h`, handle `0x0005`에 대한 current-relative file seek 요청으로 본다.

DOS `AH=42h`는 `AL` origin, `BX` handle, `CX:DX` signed offset을 사용한다. 성공 시 carry를 clear하고 새 file position을 `DX:AX`로 반환한다. 실패 시 carry를 set하고 `AX`에 DOS error code를 반환한다.

HLE는 기존 `DosOpenFileHandle::file_offset`을 갱신한다. `AL=0`은 파일 시작 기준, `AL=1`은 현재 offset 기준, `AL=2`는 파일 끝 기준이다. 결과 위치가 음수면 실패로 처리한다. DOS는 EOF 너머 seek를 허용할 수 있으므로, 양수 위치는 file size를 넘어도 허용한다. 반환 위치는 현재 32-bit DOS API에 맞춰 `0..0xFFFFFFFF` 범위만 허용한다.

검증은 `piu_1st`가 기존 `AH=42h` 지점을 통과하고 다음 관측 지점으로 이동하는지 확인한다. Win32 loader 로그에는 마지막 DOS seek handle, origin, signed offset, result position, 결과를 출력한다.

# INT 21h AH=42h File Seek HLE Design

After passing `AH=3Fh` file read, `piu_1st` stops at `CD 21` at relocated base + `0x000F79D4`. With exception-time `EAX=0x00004201`, `EBX=0x00000005`, `ECX=0`, and `EDX=0`, this is treated as DOS `INT 21h AH=42h AL=01h`, a current-relative file seek for handle `0x0005`.

DOS `AH=42h` uses `AL` origin, `BX` handle, and signed `CX:DX` offset. On success it clears carry and returns the new file position in `DX:AX`. On failure it sets carry and returns a DOS error code in `AX`.

The HLE updates the existing `DosOpenFileHandle::file_offset`. `AL=0` is start-relative, `AL=1` is current-relative, and `AL=2` is end-relative. Negative resulting positions fail. DOS can allow seeking beyond EOF, so positive positions beyond file size are allowed. Returned positions are limited to the 32-bit DOS API range `0..0xFFFFFFFF`.

Verification checks that `piu_1st` passes the previous `AH=42h` point and reaches the next observed point. The Win32 loader log prints the last DOS seek handle, origin, signed offset, result position, and result.
