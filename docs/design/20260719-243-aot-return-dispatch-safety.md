# AOT RET Dispatcher Safety Design

## Design

The current AOT RET inline-cache fast-path compares the stack return address and executes
`lea esp, [esp + pop_bytes]; jmp cache_target` rather than the original `RET`. The PIU
`0x0304EBA0` observation, where its 24-byte frame remains and return reaches zero, means this
fast-path or its re-entry path does not preserve guest ESP.

Route every RET through the existing breakpoint return dispatcher. It reads the return address
at the current guest ESP, explicitly advances by `pop_bytes`, and re-enters the resolved cache
target. This preserves the guest ABI and is already the inline-cache miss path. Correctness takes
priority; re-enable the RET inline cache only after this epilogue and long-run differential pass.
