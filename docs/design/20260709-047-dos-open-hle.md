# DOS File Open HLE 설계

## 배경

`INT 21h AH=0x3B` current-directory HLE 이후 `piu_1st`는 `0x020F740C`의 `CD 21`에서 중단된다. 직전 명령이 `B4 3D`이므로 이 호출은 DOS `INT 21h AH=0x3D` file open 요청이다.

## 정책

`open`은 기존 `DosVirtualFileSystemState`의 가상 current directory와 path resolver를 사용한다. Host process current directory는 계속 변경하지 않는다.

DOS handle은 HLE 내부 handle table로 관리한다. 표준 handle `0..4`는 예약된 것으로 보고, 파일 open 결과는 `5`부터 할당한다. 이번 단계에서는 open 성공 여부와 handle 할당만 구현하고, 실제 read/write/close 동작은 후속 작업으로 남긴다.

## `INT 21h AH=0x3D`

`DS:DX`가 가리키는 ASCIZ 경로를 읽는다. 현재 trace에서는 `EDX`가 relocated runtime arena 안의 linear pointer로 관측되므로, 이번 단계에서는 `EDX`를 직접 guest linear address로 읽는다.

처리 결과:

* 대상 경로가 target working directory 아래의 실제 regular file이면 성공, CF clear, `AX=handle`.
* 경로가 없거나 regular file이 아니면 실패, CF set, `AX=0x0002`.
* 루트 밖 탈출이 감지되면 실패, CF set, `AX=0x0005`.
* guest 문자열을 읽을 수 없으면 실패, CF set, `AX=0x0002`.

## 범위

이번 작업은 path resolve, host file 존재 확인, DOS handle 할당까지만 포함한다. 파일 내용 읽기, 쓰기, seek, close는 다음 파일 HLE 작업에서 구현한다.

# DOS File Open HLE Design

## Background

After `INT 21h AH=0x3B` current-directory HLE, `piu_1st` stops at `CD 21` at `0x020F740C`. The preceding instruction is `B4 3D`, so this is a DOS `INT 21h AH=0x3D` file open request.

## Policy

`open` uses the virtual current directory and path resolver from `DosVirtualFileSystemState`. The host process current directory remains unchanged.

DOS handles are managed by an HLE handle table. Standard handles `0..4` are treated as reserved, and opened files receive handles starting at `5`. This step only implements open success/failure and handle allocation; actual read/write/close behavior remains follow-up work.

## `INT 21h AH=0x3D`

Read the ASCIZ path pointed to by `DS:DX`. In the current trace, `EDX` is observed as a linear pointer inside the relocated runtime arena, so this step reads `EDX` directly as a guest linear address.

Result handling:

* If the target path is an existing regular file under the target working directory, succeed, clear CF, and return `AX=handle`.
* If the path does not exist or is not a regular file, fail, set CF, and return `AX=0x0002`.
* If escaping above the root is detected, fail, set CF, and return `AX=0x0005`.
* If the guest string cannot be read, fail, set CF, and return `AX=0x0002`.

## Scope

This task only includes path resolution, host file existence checking, and DOS handle allocation. File content reads, writes, seeks, and close handling belong to later file HLE work.
