# INT 21h AH=0x30 HLE 설계

## 배경

`piu_1st`는 `STI` HLE trap을 통과한 뒤 relocated address `0x020F38B5`에서 `CD 21`에 도달한다.
직전 byte pattern은 `B4 30 CD 21`이므로 이 호출은 DOS version query인 `INT 21h AH=0x30`으로 볼 수 있다.

현재 `dos4gw_hello` 전용 DOS HLE 경로에는 `AH=0x30` 처리가 있지만, 이 경로는 console output과 DOS memory access HLE까지 함께 켠다.
`piu_1st`에는 먼저 trace로 확인된 `AH=0x30`만 연결해 다음 요구사항을 관찰한다.

## 설계

Win32 execution trampoline에 DOS version query HLE 플래그를 별도로 추가한다.

* `enable_privileged_trap_hle`: `CLI`/`STI` 처리
* `enable_dos_version_hle`: `INT 21h AH=0x30` 처리
* `enable_dos_hle`: hello 샘플의 console/DOS memory HLE 처리

`INT 21h AH=0x30` 처리 규칙은 기존 hello 경로와 같은 값을 사용한다.

* `AX = 0x0007`
* `EBX = 0`
* `ECX = 0`
* carry flag clear
* `EIP += 2`

execution attempt에는 처리된 DOS interrupt count, 마지막 interrupt vector, 마지막 DOS AH 값을 기록한다.

## 검증

* Win32 x86 loader 빌드가 성공해야 한다.
* `piu_1st` 실행에서 handled DOS interrupt count가 1 이상이어야 한다.
* 마지막 DOS interrupt vector는 `0x21`, 마지막 AH는 `0x30`이어야 한다.
* 실행은 `0x020F38B5`에서 멈추지 않고 다음 중단 지점으로 진행해야 한다.
* `dos4gw_hello` 출력은 유지되어야 한다.

# INT 21h AH=0x30 HLE Design

## Background

After passing the `STI` HLE trap, `piu_1st` reaches `CD 21` at relocated address `0x020F38B5`.
The preceding byte pattern is `B4 30 CD 21`, so this call is DOS version query `INT 21h AH=0x30`.

The `dos4gw_hello` DOS HLE path already handles `AH=0x30`, but that path also enables console output and DOS memory access HLE.
For `piu_1st`, this task connects only the traced `AH=0x30` service first so the next requirement can be observed.

## Design

Add a separate DOS version query HLE flag to the Win32 execution trampoline.

* `enable_privileged_trap_hle`: handles `CLI`/`STI`
* `enable_dos_version_hle`: handles `INT 21h AH=0x30`
* `enable_dos_hle`: handles console/DOS memory HLE for the hello sample

`INT 21h AH=0x30` uses the same response as the existing hello path.

* `AX = 0x0007`
* `EBX = 0`
* `ECX = 0`
* clear carry flag
* `EIP += 2`

The execution attempt records handled DOS interrupt count, the last interrupt vector, and the last DOS AH value.

## Verification

* Win32 x86 loader build must pass.
* `piu_1st` should report handled DOS interrupt count at least 1.
* The last DOS interrupt vector should be `0x21`, and the last AH should be `0x30`.
* Execution should no longer stop at `0x020F38B5`; it should proceed to the next stop.
* `dos4gw_hello` output must be preserved.
