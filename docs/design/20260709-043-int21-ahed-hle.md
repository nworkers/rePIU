# INT 21h AH=0xED HLE 설계

## 배경

DS low-memory 읽기 흐름을 처리한 뒤 `piu_1st`는 relocated address `0x020FBAF8`에서 `CD 21`에 도달한다. 예외 시점의 `EAX=0x025DED2B`이므로 이 호출은 `INT 21h AH=0xED`로 볼 수 있다.

`AH=0xED`는 표준 DOS API로 확정하기 어렵다. 기존 일반 DOS HLE 경로에는 이미 `AH=0xED`가 `AH=0xFF`와 같은 최소 응답으로 구현되어 있다. 그러나 `piu_1st`는 전체 DOS HLE를 켜지 않고 trace 기반 `INT 21h` 처리만 사용하므로, 현재 관측된 함수만 trace 기반 핸들러에 추가한다.

## 설계

`HandleTracedDosInterrupt21`에 `AH=0xED` 처리를 추가한다.

처리 규칙은 기존 일반 DOS HLE의 `AH=0xED` 및 trace 기반 `AH=0xFF`와 동일하게 둔다.

* `AL = 0`
* carry flag clear
* `EIP += 2`
* 마지막 처리된 DOS interrupt 기록을 `vector=0x21`, `AH=0xED`로 갱신

이 응답은 의미가 확정된 구현이 아니라, 원본 DOS/4G 런타임이 다음 경로로 진행하는지 확인하기 위한 최소 HLE 응답이다.

## 검증

* `scripts\test_all.ps1`이 통과해야 한다.
* `piu_1st`가 `0x020FBAF8`의 `INT 21h AH=0xED`에서 멈추지 않고 다음 관측 지점까지 진행해야 한다.
* OpenWatcom 샘플 baseline 비교에서 회귀가 없어야 한다.

# INT 21h AH=0xED HLE Design

## Background

After handling the DS low-memory read flow, `piu_1st` reaches `CD 21` at relocated address `0x020FBAF8`. Since exception-time `EAX=0x025DED2B`, this call is interpreted as `INT 21h AH=0xED`.

`AH=0xED` is not confirmed as a standard DOS API. The existing general DOS HLE path already implements `AH=0xED` with the same minimal response as `AH=0xFF`. However, `piu_1st` does not enable the full DOS HLE path; it uses only trace-based `INT 21h` handling. Therefore, only this observed function is added to the trace-based handler.

## Design

Add `AH=0xED` handling to `HandleTracedDosInterrupt21`.

Use the same behavior as the existing general DOS HLE `AH=0xED` and trace-based `AH=0xFF` handling.

* `AL = 0`
* clear carry flag
* `EIP += 2`
* record the last handled DOS interrupt as `vector=0x21`, `AH=0xED`

This response does not finalize the semantic meaning. It is the minimal HLE response used to check whether the original DOS/4G runtime can proceed to the next path.

## Verification

* `scripts\test_all.ps1` must pass.
* `piu_1st` must no longer stop at `INT 21h AH=0xED` at `0x020FBAF8`; it should proceed to the next observed point.
* OpenWatcom sample baseline comparison must show no regressions.
