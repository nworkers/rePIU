# Win32 x86 빌드 구성 설계

## 배경

Win32 runtime memory policy는 64-bit host process에서 원본 32-bit x86 entry 직접 실행을 unsupported로 보고한다.

원본 DOS/4GW 보호 모드 코드를 직접 호출하려면 32-bit host process 빌드가 필요하다.

이번 단계는 실제 원본 entry 호출이 아니라, 32-bit Win32 빌드가 가능하고 analyzer가 32-bit host pointer를 보고하는지 확인하는 것이다.

## 목표

* Win32 x86 CMake 빌드 스크립트를 추가한다.
* Debug Win32 빌드를 검증한다.
* Win32 빌드의 analyzer가 host pointer bits 32를 보고하는지 확인한다.
* 기존 x64 Debug 빌드와 병행 가능한 build directory를 사용한다.

## 비목표

* 원본 코드 실행
* 실행 메모리 할당
* `VirtualAlloc` 구현
* 32-bit helper process 설계

## 설계

새 스크립트는 `scripts/build_win32_x86.bat`에 둔다.

Visual Studio CMake generator를 `Visual Studio 17 2022`, platform을 `Win32`로 지정한다.

빌드 출력 디렉터리는 기존 x64 빌드와 충돌하지 않도록 `build\vs2022_win32_debug`를 사용한다.

## 검증 기준

* `scripts\build_win32_x86.bat` 실행이 성공한다.
* `build\vs2022_win32_debug\Debug\repiu_exe_analyzer.exe` 실행이 성공한다.
* 출력에 `Win32 host pointer bits: 32`가 포함된다.
* 출력에 `Win32 direct x86 execution: supported`가 포함된다.

## 향후 확장

다음 단계에서 32-bit host 빌드를 기준으로 실제 executable memory allocation dry-run을 추가한다.

## Background

The Win32 runtime memory policy reports direct original 32-bit x86 entry execution as unsupported in a 64-bit host process.

Directly calling original DOS/4GW protected-mode code requires a 32-bit host process build.

This step does not call the original entry point. It verifies that a 32-bit Win32 build is possible and that the analyzer reports a 32-bit host pointer.

## Goal

* Add a Win32 x86 CMake build script.
* Verify a Debug Win32 build.
* Confirm that the Win32 analyzer reports host pointer bits as 32.
* Use a build directory that can coexist with the existing x64 Debug build.

## Non-Goals

* Executing original code.
* Allocating executable memory.
* Implementing `VirtualAlloc`.
* Designing a 32-bit helper process.

## Design

The new script is placed at `scripts/build_win32_x86.bat`.

It uses the Visual Studio CMake generator `Visual Studio 17 2022` with platform `Win32`.

The build output directory is `build\vs2022_win32_debug` so it does not conflict with the existing x64 build.

## Verification Criteria

* `scripts\build_win32_x86.bat` succeeds.
* `build\vs2022_win32_debug\Debug\repiu_exe_analyzer.exe` runs successfully.
* Output includes `Win32 host pointer bits: 32`.
* Output includes `Win32 direct x86 execution: supported`.

## Future Extension

A later step will add an executable memory allocation dry-run based on the 32-bit host build.
