# INT 21h AH=25h 인터럽트 벡터 설정 설계

## 배경

`INT 21h AH=35h AL=09h`를 통과한 뒤 `piu_1st`는 relocated base + `0x000F4987`의 `CD 21`에서 중단되었다. 당시 `EAX=0x00002509`였으므로 요청은 `INT 21h AH=25h AL=09h`, 즉 interrupt 09h vector 설정이다.

이는 원본 코드가 keyboard interrupt vector를 조회한 뒤 자체 vector를 설치하려는 흐름으로 보인다.

## 설계

DOS HLE에 작은 interrupt vector table shadow를 추가한다.

* `ThreadContext` 안에 256개 vector의 `segment:offset` shadow를 둔다.
* `AH=25h`는 `AL` vector 번호에 대해 `DS:DX` 값을 저장하고 carry flag를 clear한다.
* `AH=35h`는 저장된 값이 있으면 해당 `segment:offset`을 `ES:BX`로 반환하고, 없으면 기존처럼 `0000:0000`을 반환한다.
* 실제 keyboard IRQ나 host interrupt 연결은 하지 않는다.
* 일반 DOS interrupt handler와 traced DOS interrupt handler 모두 같은 helper를 사용한다.

이 방식은 원본 코드의 interrupt vector bookkeeping을 보존하되, 아직 하드웨어/IRQ 실행 모델을 도입하지 않는 HLE 경계 안에 머문다.

## 기대 결과

`piu_1st`는 interrupt 09h vector 설정 지점을 통과하고 다음 HLE 요구사항으로 이동해야 한다.

## 범위 밖

* 실제 interrupt dispatch
* host keyboard input 연결
* DOS IVT low-memory layout 전체 구현

# INT 21h AH=25h Set Vector Design

## Background

After passing `INT 21h AH=35h AL=09h`, `piu_1st` stopped at `CD 21` at relocated base + `0x000F4987`. `EAX=0x00002509`, so the request is `INT 21h AH=25h AL=09h`, set interrupt 09h vector.

This appears to be the original code installing its own keyboard interrupt vector after querying the previous vector.

## Design

Add a small interrupt vector table shadow to the DOS HLE.

* Store 256 `segment:offset` vector entries in `ThreadContext`.
* `AH=25h` stores `DS:DX` for the `AL` vector number and clears carry flag.
* `AH=35h` returns the stored `segment:offset` through `ES:BX` when present, or `0000:0000` when absent.
* Do not connect real keyboard IRQ or host interrupt handling.
* Use shared helpers from both the normal DOS interrupt handler and the traced DOS interrupt handler.

This preserves the original code's interrupt vector bookkeeping while staying within the current HLE boundary without introducing hardware/IRQ execution.

## Expected Result

`piu_1st` should pass the interrupt 09h vector installation point and move to the next HLE requirement.

## Out Of Scope

* Real interrupt dispatch
* Host keyboard input wiring
* Full DOS IVT low-memory layout
