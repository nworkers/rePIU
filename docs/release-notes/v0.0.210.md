## rePIU v0.0.210

이전 릴리스 **v0.0.209** 이후의 변경입니다(issue #25). **이미 답이 나온 조사를 위해 넣었던
일회성 진단 9개를 지웠습니다.** 지운 코드는 모두 해당 변수를 켰을 때만 돌던 것이라, 아무
변수도 주지 않은 실행의 동작은 v0.0.209와 같습니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#25](https://github.com/reexec/rePIU/issues/25) | 이미 답이 나온 질문을 위한 일회성 진단 삭제(환경 변수 토글 정리 후속) | `b24ca84` |

### 바뀐 것

**더 이상 읽지 않는 환경 변수 9개.** 설정해도 아무 효과가 없습니다.

* Glide: `REPIU_GLIDE_CALL_AUDIT`, `REPIU_GLIDE_TEX_CENSUS`, `REPIU_GLIDE_DRAW_CENSUS`,
  `REPIU_GLIDE_TRI_CENSUS`, `REPIU_GLIDE_FRAME_DUMP`, `REPIU_DUMP_LFB_BMP`,
  `REPIU_GLIDE_VERTEX_DEPTH_CENSUS`
* 그 밖: `REPIU_LOWMEM_TRACE`, `REPIU_AOT_PROBE_GUEST`

ordinal별 호출 수와 첫 인자는 종료 로그의 `Glide call trace` 줄에, 텍스처 형식·크기 집계는
기본 텍스처 census에, 텍스처 덤프는 `REPIU_GLIDE_TEX_DUMP`(TGA)에 그대로 있습니다.

**종료 로그.** 위 변수를 켰을 때만 찍히던 `Glide vertex depth census …`와
`AOT runtime cache probe …` 줄이 없어졌습니다. 기본 실행의 출력은 바뀌지 않습니다.

**성능.** `REPIU_DUMP_LFB_BMP`는 LFB 화면을 내보낼 때마다 `getenv`를 불렀는데, 그 호출이
없어졌습니다.

**남긴 것.** 후보였던 `REPIU_AOT_DBT_CALL_TRACE`, `REPIU_AOT_RETIRED_TRAP_PROFILE`,
`REPIU_GLIDE_SETTER_CENSUS`, `REPIU_GLIDE_SETTER_PHASE`는 살아 있는 기구를 재거나 가이드·
스크립트가 쓰므로 그대로 동작합니다.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Win32 Release | 빌드, `repiu_aot_probe` 전체 체인(종료 코드 0), Glide probe 2종 |
| Linux x64 Release | 빌드, core probe 전체 통과 |

### 알려진 것

* 게임 실행은 하지 않았습니다. 지운 코드는 기본 실행 경로에 닿지 않습니다.
* Linux i386 빌드는 확인하지 않았습니다.
* Win32 core probe의 `stack_bridge` 실패는 이전부터 있던 것입니다(#8).

## rePIU v0.0.210

Changes since **v0.0.209** (issue #25). **Nine one-off diagnostics added for investigations that
are already answered are gone.** Every deleted block ran only with its variable set, so a run with
nothing set behaves as v0.0.209 did.

### Resolved issues

| issue | Summary | Commit |
|---|---|---|
| [#25](https://github.com/reexec/rePIU/issues/25) | Delete one-off diagnostics for answered questions (environment toggle cleanup follow-up) | `b24ca84` |

### Changed

**Nine variables are no longer read**; setting them has no effect: `REPIU_GLIDE_CALL_AUDIT`,
`REPIU_GLIDE_TEX_CENSUS`, `REPIU_GLIDE_DRAW_CENSUS`, `REPIU_GLIDE_TRI_CENSUS`,
`REPIU_GLIDE_FRAME_DUMP`, `REPIU_DUMP_LFB_BMP`, `REPIU_GLIDE_VERTEX_DEPTH_CENSUS`,
`REPIU_LOWMEM_TRACE` and `REPIU_AOT_PROBE_GUEST`. Per-ordinal call counts and first arguments
remain in the final log's `Glide call trace` lines, texture format and size counts in the default
texture census, and texture dumps in `REPIU_GLIDE_TEX_DUMP` (TGA).

**Final log**: the `Glide vertex depth census …` and `AOT runtime cache probe …` lines, printed
only with those variables set, are gone; default output is unchanged.

**Performance**: `REPIU_DUMP_LFB_BMP` called `getenv` on every LFB present; that call is gone.

**Kept**: the candidates `REPIU_AOT_DBT_CALL_TRACE`, `REPIU_AOT_RETIRED_TRAP_PROFILE`,
`REPIU_GLIDE_SETTER_CENSUS` and `REPIU_GLIDE_SETTER_PHASE` still work, since they measure a live
mechanism or a guide or script uses them.

### Verified

* Win32 Release: build; the full `repiu_aot_probe` chain (exit 0); both Glide probes.
* Linux x64 Release: build; all core probes pass.

### Known

* No game run; the deleted code is not on the default execution path.
* The Linux i386 build was not checked.
* The Win32 core probe's `stack_bridge` failure predates this release (#8).
