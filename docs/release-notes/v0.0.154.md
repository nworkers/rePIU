## rePIU v0.0.154

이전 릴리스 **v0.0.153** 이후의 변경입니다. 이번 릴리스는 DOS 날짜 설정을 실행별
가상 상태로 지원하고, MAME Pump It Up target profile을 22개 전체 카탈로그로
정리하며, clone의 CAT702 자산을 부모 ROM 세트에서 안전하게 상속합니다.

### 가상 DOS 시스템 날짜

- `INT 21h/AH=2Bh` Set System Date를 구현했습니다. 유효한 날짜는 host local date 대비
  일수 offset으로 실행 context에 저장됩니다.
- `AH=2Ah` Get System Date는 설정된 가상 날짜와 해당 요일을 반환합니다. 실제 Windows
  시스템 날짜는 변경하지 않습니다.
- 일반 DOS HLE와 traced/AOT 경로가 같은 계약을 사용하며, 날짜 검증과 set/get
  round trip을 probe로 고정했습니다.
- 사용자가 실제 실행에서 날짜 설정 이후 진행이 정상임을 확인했습니다.

### 22개 Pump It Up target profile

- 기존 14개 MAME profile을 `xtom3d.cpp`의 22개 `GAME` 카탈로그 순서로 확장했습니다.
  누락됐던 `pumpit2a`, `pumpit3a`, `pumpitpru`, `pumpitea`, `pumpipx2p`,
  `pumpitp3a`, `pumpipx3a`, `pumpipx3b`를 추가했습니다.
- display name에 버전·연도·날짜를 보존하고 브랜드 표기를 `Pump It Up`으로
  통일했습니다.
- 임시 `piu_1st` profile을 제거하고 runner, supervisor와 analyzer의 기본 target을
  `pumpit1`로 변경했습니다.

### 부모 ROM 세트 CAT702 fallback

- 모든 PIU profile에 MAME의 직접 parent ROM 세트 ID를 명시했습니다.
- CAT702은 현재 ZIP의 현재 이름, 같은 ZIP의 부모 이름, 형제 부모 ZIP의 부모 이름
  순서로 조회합니다. 항목 없음일 때만 다음 단계로 진행하며 archive, 추출과 CRC 오류는
  fallback으로 숨기지 않습니다.
- 실제 `pumpitpru` 실행에서 `pumpitpr.cat702` 8바이트 항목을 선택해 PIU10을
  초기화했습니다. 관찰된 PIU10 port I/O 33회가 모두 처리되고 Glide 초기화까지
  진행했습니다.

### 검증

- Win32 x86 Debug/Release 전체 빌드가 성공했습니다.
- 두 구성의 `pumpipx3` 전체 AOT probe가 exit 0이며
  `piu10_target_profiles=true`, `dos_date_probe=pass`, `coherence_all=true`를
  확인했습니다.
- Debug/Release `--piu10` probe에서 profile, CAT702 vector, MP3 ring과 frame audit가
  모두 통과했습니다.
- 기존 C4819와 LNK4217 경고만 남았습니다.

## rePIU v0.0.154

Changes since **v0.0.153**. This release supports DOS date setting as per-run
virtual state, expands the MAME Pump It Up target registry to the complete
22-entry catalog, and safely inherits clone CAT702 assets from parent ROM sets.

### Virtual DOS system date

- Implemented `INT 21h/AH=2Bh` Set System Date. A valid date is stored in the
  execution context as a day offset from the host's local date.
- `AH=2Ah` Get System Date returns the virtual date and its weekday without
  changing the real Windows system date.
- Ordinary DOS HLE and traced/AOT paths share the same contract, covered by date
  validation and set/get round-trip probes.
- The user confirmed normal progress after date setting in a real run.

### Complete 22-entry Pump It Up target catalog

- Expanded the previous 14 MAME profiles to the 22-entry `GAME` catalog order
  from `xtom3d.cpp`, adding `pumpit2a`, `pumpit3a`, `pumpitpru`, `pumpitea`,
  `pumpipx2p`, `pumpitp3a`, `pumpipx3a`, and `pumpipx3b`.
- Preserved version, year, and date details in display names and normalized the
  brand spelling to `Pump It Up`.
- Removed the temporary `piu_1st` profile and changed runner, supervisor, and
  analyzer defaults to `pumpit1`.

### Parent ROM-set CAT702 fallback

- Every PIU profile now records its direct MAME parent ROM-set ID.
- CAT702 lookup checks the current name in the current ZIP, the parent name in
  that ZIP, then the parent name in the sibling parent ZIP. Only an absent member
  advances to fallback; archive, extraction, and CRC failures remain visible.
- A real `pumpitpru` run selected the eight-byte `pumpitpr.cat702` member,
  initialized PIU10, handled all 33 observed PIU10 port-I/O operations, and
  reached Glide initialization.

### Verification

- Full Win32 x86 Debug and Release builds passed.
- Full `pumpipx3` AOT probes exited zero in both configurations with
  `piu10_target_profiles=true`, `dos_date_probe=pass`, and `coherence_all=true`.
- Debug and Release `--piu10` probes passed the profile, CAT702 vector, MP3 ring,
  and frame-audit checks.
- Only the existing C4819 and LNK4217 warnings remain.
