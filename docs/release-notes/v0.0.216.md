## rePIU v0.0.216

이전 릴리스 **v0.0.215** 이후의 변경입니다(issue #52). **게임패드만으로 게임과 런처를 끝낼 수 있습니다.**
키보드도 창 닫기 버튼도 없는 스팀덱을 위한 조합입니다. v0.0.215를 쓰고 있다면 이 버전은 런처의
**Update** 버튼으로 받을 수 있는 첫 릴리스입니다.

### 해결된 issue

| issue | 내용 | 커밋 |
|---|---|---|
| [#52](https://github.com/reexec/rePIU/issues/52) | 게임패드 종료 조합 LT+RT+L3+R3 1초 | `8d0b378` |

### 바뀐 것

**게임패드 종료 조합.** 한 패드에서 **LT + RT + 왼쪽 스틱 누르기 + 오른쪽 스틱 누르기**를 **1초** 동안 함께
누르고 있으면 끝냅니다.

| 어디서 | 결과 |
|---|---|
| 게임 중 | 창을 닫은 것과 같이 게임이 끝나고 런처로 돌아감(인자 실행이면 프로세스가 끝남) |
| 런처 | 런처가 닫히고 rePIU가 끝남(스팀덱에서는 Steam으로 돌아감) |

1초가 되기 전에 떼면 아무 일도 없습니다. 오른쪽 스틱 누르기는 기본으로 `CLEAR`에 묶여 있어, 조합을 누르는
동안 게임에 CLEAR가 들어갑니다. 런처 안내 문구에도 조합을 적었고, 스팀덱 설치 순서는
[런처 업데이트 가이드](../guides/launcher-update.md)에 있습니다.

### 확인한 것

| 구성 | 확인 |
|---|---|
| Linux x64·i386 Release | 빌드, core probe(새 `host_pad_input_exit_chord` 포함) |
| Win32 | CI Debug 빌드와 probe |
| 실제 패드(Xbox Series X, Linux x64) | 게임 중 1초 유지 → 정상 종료 후 런처 복귀, 짧게 누르기와 런처 종료는 사용자가 화면으로 확인 |
| v0.0.215 릴리스 실행 | 첫 시도에 모든 잡 통과, Node.js 20 경고 없음, Linux x64 `host_thread_interrupt` 주장 모두 참(#50, #12) |

### 알려진 것

* 스팀덱 실기에서는 확인하지 않았습니다.
* 조합을 누르는 동안 게임에 CLEAR가 들어갑니다(결정에 따른 동작).

## rePIU v0.0.216

Changes since **v0.0.215** (issue #52). **A gamepad alone can now quit the game and the launcher**, a chord for the
Steam Deck, which has no keyboard or close button. If you run v0.0.215, this is the first release its launcher's
**Update** button can install.

### Resolved issues

| issue | Summary | Commit |
|---|---|---|
| [#52](https://github.com/reexec/rePIU/issues/52) | Gamepad exit chord LT+RT+L3+R3 held for one second | `8d0b378` |

### Changed

**Gamepad exit chord.** Holding **LT + RT + left stick click + right stick click** together on one pad for **one
second** quits: in a game it ends the game as closing the window does and returns to the launcher (an argument
run ends the process); in the launcher it closes the launcher and ends rePIU (back to Steam on a Steam Deck).
Releasing sooner does nothing. The right stick click is bound to `CLEAR` by default, so the game sees CLEAR while
the chord is held. The launcher's hint line names the chord, and the Steam Deck steps are in the
[launcher update guide](../guides/launcher-update.md).

### Verified

* Linux x64 and i386 Release: builds and the core probe, including the new `host_pad_input_exit_chord`.
* Win32: the CI Debug build and probes.
* A real pad (Xbox Series X, Linux x64): a one-second hold in a game ended it normally and returned to the
  launcher; the user confirmed the short press and the launcher quit on screen.
* The v0.0.215 release run passed every job on its first attempt, with no Node.js 20 warning and every Linux x64
  `host_thread_interrupt` claim true (#50, #12).

### Known

* Not checked on a real Steam Deck.
* The game sees CLEAR during the chord (the decided behavior).
